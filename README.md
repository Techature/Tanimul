<h1 align="center">🐾 Tanimul ✨</h1>

<p align="center">
  <b>Say something... and watch an animal say it back!</b>
</p>

<p align="center">
  Tanimul is a fun little web app that listens to your voice and plays a matching animal animation "speaking" your sound. 💚 Built by <a href="https://github.com/Techature">Techature</a>.
</p>

---

### 🌱 What it does

1. Pick an animal 😺🐝🐶
2. You record your voice 🎙️
3. Watch the animal "say" it with a fun animation!

### 🛠️ Built with

- **Vite** + **TypeScript**
- **Tailwind CSS**

### 🚀 Getting started

```bash
git clone https://github.com/Techature/Tanimul.git
cd Tanimul
npm run dev
```

Then open the local link it gives you in your browser!
